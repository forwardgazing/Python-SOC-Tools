# 🐍 Python SOC Tools

Коллекция скриптов на Python для автоматизации рутинных задач аналитика SOC L1 и DevSecOps.

## 📜 Скрипт `log_analyzer.py`

**Задача:** Автоматический поиск, подсчет и приоритизация IP-адресов в логах для выявления признаков брутфорса (Brute-force) и аномальной активности.

**Ключевые возможности:**
*   Поиск IPv4-адресов с помощью регулярных выражений (RegEx).
*   Вывод Топ-N самых активных IP-адресов.
*   **Интерфейс командной строки (CLI)** на базе библиотеки `argparse` для гибкой настройки.
*   **Экспорт результатов в формат JSON** для дальнейшей интеграции с другими системами.
*   Валидация входных данных и обработка ошибок (отсутствие файла, ошибки чтения).

### 🛠️ Примеры использования:

**1. Базовый запуск** (проанализирует `sample_auth.log` по умолчанию и покажет Топ-5 IP):

    python log_analyzer.py

**2. Указание конкретного файла:**

    python log_analyzer.py -f /path/to/your/logfile.log

**3. Сохранение отчета в JSON** (создаст файл `scan_report.json`):

    python log_analyzer.py -f logs.txt -j

## 🛠️ Стек технологий
*   Python 3.x
*   Стандартные библиотеки: `re`, `argparse`, `json`, `collections`, `os`.
