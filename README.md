# 🐍 Python SOC Tools

Коллекция скриптов на Python для автоматизации рутинных задач аналитика SOC L1.

## 📜 Скрипт `log_analyzer.py`
**Задача:** Автоматический поиск и подсчет IP-адресов в логах для выявления признаков брутфорса (Brute-force).
**Как работает:** Скрипт использует регулярные выражения (RegEx) для извлечения IPv4-адресов из текстового файла и выводит топ-5 самых частых адресов.

**Запуск:**
```bash
python log_analyzer.py
